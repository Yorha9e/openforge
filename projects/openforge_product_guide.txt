OpenForge 产品说明文档
======================

一、产品定位

OpenForge 是一个 AI 驱动的端到端全栈开发工作台。它让产品经理通过自然语言对话即可完成软件开发全流程——从需求澄清、方案拆解、代码实现、自动化测试到部署验证，无需编写一行代码。开发者的角色从"翻译需求为代码"转变为"审查 AI 产出并做关键决策"，大幅降低软件交付的人力门槛和时间成本。

项目以 Conduit（RealWorld 前后端 monorepo）为实验田，验证了 AI 在真实全栈项目中的端到端交付能力。

二、目标用户

主要面向三类用户：第一，企业产品经理和业务人员，可直接通过对话交付内部工具和后台管理系统，无需等待开发排期；第二，全栈开发团队负责人，利用 Pipeline 引擎标准化研发流程，让 AI 处理重复性编码工作，团队聚焦架构决策和代码审查；第三，合规与安全管理人员，通过硬件级 Gate 审批链和不可篡改的 WORM 审计日志，确保每次变更都经过授权并且全程可追溯。

三、核心能力

需求到部署全链路自动化。用户用自然语言描述需求，系统自动判定复杂度等级（L1 原子变更至 L4 架构变更），规划 Pipeline 阶段，调度 Agent Swarm 执行具体工作。每个阶段之间设有 Gate 审批卡点，支持人工介入、驳回和回溯，确保 AI 产出始终在人的控制之下。

多 Agent 协作引擎。Agent Swarm 支持 Spawn（派生子 Agent 处理子任务）、Delegate（委托给专用 Agent）、Broadcast（向所有 Agent 广播消息）三种协作模式。内置七个核心工具——文件读写、代码搜索、Shell 执行、Git 操作、Web 获取等，Agent 可自主选择和组合工具完成任务。

完整的开发工作台界面。前端提供 ProMode 多面板布局，包括 AI 对话面板、代码 Diff 审查面板、文件树面板、终端面板、项目拓扑图面板、测试报告面板和审批面板。PM 在一个界面内完成从需求到部署的全部操作。

多模型路由与成本控制。LLM Router 支持 Anthropic Claude、OpenAI、DeepSeek 等多家模型供应商，自动翻译请求格式。Token 用量实时计量，成本看板按日、按模型维度展示消耗，预算仪表提供超额预警。

企业级安全与合规。WORM 审计日志按月分区存储，写入后不可篡改。数据生命周期管理自动归档和清理过期数据。Docker 沙箱提供五层安全防御——危险命令阻断、Shell 注入防护、资源限制、网络隔离、只读根文件系统。JWT 认证加基于角色的访问控制（RBAC），支持 OIDC 外部身份集成。

渐进式运维部署。MVP 阶段仅需五个容器（Go、Node.js、React、PostgreSQL、Docker）即可运行完整系统。随团队规模增长，可平滑引入 Redis 队列、MinIO 对象存储、Kubernetes 编排、Vault 密钥管理、Grafana 监控等企业基础设施，通过 Capability Profile YAML 配置一键切换 minimal、standard、enterprise 三档，无需修改业务代码。

四、竞争定位

相较于 GitHub Copilot、Cursor 等 AI 编码助手（面向开发者、缺乏端到端流程），以及 Devin 等 AI 开发智能体（有人工介入但无强制审批机制），OpenForge 的三道护城河是：不可跳过的硬件 Gate 审批链，确保每次部署都经过人工确认；项目、团队、全局三层组织知识库，让 AI 越用越懂团队规范；从架构第一天就设计为气隙内网部署，数据不出企业边界，满足金融、政务等强合规行业需求。

五、技术架构概要

系统分三层正交架构。C 层为 React 加 BFF 协作工作台，负责用户界面和 WebSocket 实时通信。A 层为 Go Pipeline 引擎，管理状态机流转、Gate 审批、部署编排。B 层为 Go 加 Node.js Agent Swarm 运行时，Go 负责 CSP Channel 并发协调、检查点持久化和消息缓冲，Node.js 负责 LLM 路由、工具注册和技能加载。三层通过 gRPC 和 Connect 协议通信，全链路携带 OpenTelemetry Trace ID。

数据库基于 PostgreSQL，共 22 张表，采用 UUID v7 主键支持时序排序，WORM 审计日志按月自动分区。缓存一致性分三级管理——Pipeline 状态同步写入确保强一致，检查点和文件锁异步刷盘保证五秒内准实时，Token 计数和配额统计走内存 ring buffer 批量落盘容忍最终一致。

六、当前状态

项目已完成三百余次提交，处于 MVP 阶段。已交付的模块包括：CLI 入口和流式对话、gRPC 六服务通信框架、Pipeline 九状态转换机加回溯限制、Gate 审批服务和前后置拦截器链、Agent 多模式协调器和七工具注册、WebSocket 双工事件推送、JWT 加 RBAC 认证授权体系、注册邀请系统。前端完成仪表盘、代码审查工作台、成本看板、CI/CD 部署监控、合规报告、管理员面板等十五个以上功能模块。
